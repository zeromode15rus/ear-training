# Слух и гриф

Домашние тренажёры музыкального слуха и грифа. Статические страницы, всё считается
в браузере: ни сервера, ни сборки, ни сети (кроме шрифтов и Tone.js с CDN).

| Страница | Про что |
|---|---|
| `index.html` | титульная со списком |
| `progress.html` | прогресс: слабые места, путаницы, занятия по дням |
| `cadence.html` | функциональный слух: ступень лада на слух |
| `solfege.html` | пение с листа: ноты + аккомпанемент, свои мелодии |
| `caged.html` | CAGED на грифе |
| `modes.html` | лады над бурдоном |
| `improv.html` | импровизация под квадрат |
| `ear_trainer.html` | ранний: пропеть соло, проверка высоты через микрофон |
| `theory_trainer.html` | ранний: ступени и аккорды без звука |

Общее: `ear-common.css` (оформление), `ear-theme.js` (переключатель темы),
`ear-kid.css` (детская тема), `ear-progress.js` (память и подбор), `ear-audio.js`,
`ear-fretboard.js`.

## Память и подбор вопросов

`ear-progress.js` держит в `localStorage` (ключ `ear-progress-v1`) журнал по каждому
вопросу: сколько раз спрашивали, сколько верно, последние десять ответов, когда
встречался в последний раз. Отдельно — матрица путаницы (что с чем перепутали)
и счётчик занятий по дням.

Следующий вопрос выбирается не равномерно: вес ступени тем больше, чем ниже её
«сила» — доля верных по последним ответам, где свежие весят больше. Давно не
встречавшееся слегка поднимается, только что отвеченное почти не повторяется,
четверть вопросов остаётся случайной, чтобы освоенное не выпадало совсем.
Новый, ни разу не заданный вопрос получает максимальный вес.

Пространства имён: `cadence` (ступени), `cadence-prog` (обороты), `modes`,
`caged` (ступени на грифе), `caged-shape`, `caged-find`.

## Темы

Кнопка в шапке переключает по кругу: как в системе → светлая → тёмная → детская.
Выбор запоминается в `localStorage` (ключ `ear-theme`).

Детская (`data-theme="kid"`) — светлая, крупные кнопки, круглые углы, фон в лапках,
три кота под шапкой и ступени подписаны по-русски: До, Фа, Соль вместо I, IV, V.

## Локально

```bash
python3 -m http.server 8777
```

Открывать по `http://127.0.0.1:8777/`, а не файлом с диска: часть страниц тянет соседние
`.js`/`.css`, и с `file://` это ломается.
